# Hotel La Fontana 360 · Panorámicas

Visor de panorámicas 360° (equirectangulares 8192×4096) del entorno del Hotel Estelar La Fontana, Unicentro y Usaquén, en Bogotá.
Renderizadas en Unreal Engine 5 con Cesium (Google Photorealistic 3D Tiles), con edificios de Catastro y árboles 3D.

- Página publicada: https://alejagoguti-cpu.github.io/TLF-360/
- Abrir un punto: `?p=pano_fontana`, `?p=pano_unicentro`, `?p=pano_usaquen`, `?p=pano_fontana_bajo`
- Giro con imágenes (Página 1): https://alejagoguti-cpu.github.io/TLF/

`panos/<nombre>_s.webp` (2048×1024) se carga primero y luego `panos/<nombre>.webp` (8192×4096).
Convención: el centro de la imagen es el norte y la derecha es el este.

Imágenes 3D: Google · Render: Unreal Engine + Cesium
